# 热线 & 未购经营看板

WPS 多维表格「社群管理系统」配套的网页看板工具。**只读源表**（热线日报表 / 未购日报表），不依赖任何统计表、合并表。

👉 在线地址：https://shuaishuai03.github.io/wps-hotline-dashboard/

## 怎么用

1. 打开任意一个战区管理系统的多维表格 → 右上「更多 → 脚本 → AirScript 脚本」
2. 新建脚本，把 [`airscript/热线未购汇总.js`](airscript/热线未购汇总.js) 全文粘进去并运行
   （也可以直接在看板里点左侧「查看 AirScript 脚本」一键复制）
3. 复制控制台打印出来的那一整段 JSON
4. 打开看板 → 左侧「导入 AirScript 数据」→ 粘贴 → 导入

数据保存在浏览器本地（localStorage），刷新不丢；点「清空数据」可清除。**不会上传到任何服务器。**

## 五个视图

| 视图 | 内容 |
|---|---|
| 经营总览 | 产出/投入/投产/客单价 KPI、热线与未购双漏斗、轮次走势、部门产出结构、广告费→产出气泡图、五张占比环形图（含投产贡献/净产出） |
| 热线经营 | 七段漏斗（进线→注册→完播→采集→定金→实发）、部门×轮次完播率热力图、轮次走势、部门规模与产出、组别排行、费用与产出占比 |
| 未购经营 | 成交漏斗、组别×轮次成交率热力图、轮次走势、首轮 vs 往期业绩堆叠、客户结构、组别成交效率排行 |
| 组织效能 | 部门/组别/员工三个维度切换，产出排行、投产排行、转化率排行、效能明细表 |
| 数据明细 | 源表原始记录（完整 34 列，横向滚动），可排序、带合计行、可导出 CSV |

顶部筛选：创建时间区间、战区、轮次、部门、组别、员工、引流渠道，所有视图联动。
源表里整列没填的维度（例如尚未启用的引流渠道）自动隐藏；**战区筛选只有 1 个战区时隐藏，2 个及以上必定出现**，
并按 一/二/三… 的实际顺序排列（而非中文字典序）。

明细表合计行只对数值列求和；一整列都没人填过时留空，不显示误导的 `¥0`。

## 指标口径（重要）

所有比率都由 **「先求和、再相除」** 计算，绝不对源表里的百分比列取平均：

| 指标 | 口径 |
|---|---|
| 注册率 / 完播率 / 采集率 / 定金率 | 各阶段合计 ÷ 进线量合计 |
| 实发转化率 | 实发单量合计 ÷ 进线量合计 |
| 实发客单 | 实发金额合计 ÷ 实发单量合计 |
| 实发投产 | 实发金额合计 ÷ 广告费合计 |
| 综合投产(实发+线上) | (实发金额 + 线上产出)合计 ÷ 广告费合计 |
| 单线索成本 | 广告费合计 ÷ 进线量合计 |
| 未购首轮完播率 | 首轮完播合计 ÷ 承接数据合计 |
| 未购成交率 | 总成交单量合计 ÷ 承接数据合计 |
| 未购客单价 | 总发货业绩合计 ÷ 总成交单量合计 |
| 总产出 | 实发金额 + 线上产出 + 总发货业绩 |
| 综合投产比 | (实发金额 + 线上产出 + 总发货业绩) ÷ (广告费 + 线索成本) |
| 投产贡献（净产出） | 各部门 产出 − 投入（投产比是比率不可直接相加，故按净产出画占比） |

### 空值口径：`""` / `null` ≠ `0`

源表里同一列会混着数字、数字字符串（`"0"`）、空串和 `null`。看板严格区分两种口径：

- **求和口径**：空串 / `null` 按 `0` 累加（没填就是没产生，加 0 是对的）
- **填报口径**：空串 / `null` 是「**没填**」，不进任何比率的分母，也不算作"填报过投入"

### 静默错数的警示（新增）

真实数据经常只有部分战区填了钱、部分列整列空着。这类情况下一个不加说明的数字比没有数字更危险，
所以看板会在页面上直接说出来，而不是安静地算完：

| 场景 | 看板行为 |
|---|---|
| 只有部分战区填了广告费/线索成本 | 顶部黄色**数据口径提示条**点名哪些战区填了、哪些全空；「综合投产比」「总投入」KPI 的副标题写明「仅 X/Y 个战区填报了投入，该比率偏高」；「实发投产 / 线上投产 / 单线索成本」指标条与「投产贡献」环形图带 ⚠；组织效能的投产排行注明排名不可跨战区比较 |
| 有产出但没填投入的记录 | 同上，改为按**记录数**提示「N/M 条有产出的记录未填投入」 |
| 有产出但没填成交单量 | 客单价类 KPI 副标题提示「客单价偏高」 |
| 各战区轮次编号体系不同（一战区 `K90`、三战区 `G98`、四战区 `S1`、五战区 `Z4`、未购 `1`） | 多战区时轮次走势图/热力图的横轴自动拆成「**战区·轮次**」，每个点只归属一个战区；图注与提示条写明「不是同一条时间轴，跨战区不可直接比较，建议先筛选战区」。筛到单个战区后横轴恢复成纯轮次，提示消失 |
| 某个漏斗环节整列没填（如「定金」「采集总」全是 `""`） | 该环节从漏斗中**跳过**（合计为 0 但后面还有非 0 环节 ⇒ 必然是没填而非真的归零），图注注明「已跳过源表未填报的环节：定金」，避免把下游环节算成「环节 0%」 |
| 大量空行（只有创建时间和渠道） | 保留在**数据明细**里，但不进占比类图表；提示条写明「N/M 条为空记录」 |
| 部门/组别未填写 | 占比类环形图过滤掉「未填写」分组，图标题注明「已过滤未填写 N 行」；明细表不受影响 |

### 日期口径

创建时间兼容三种形态，统一还原成 `YYYY-MM-DD`：ISO 串、`2026/8/31 17:26` 文本、
Excel 序列号（`46265.72`，数字或字符串都认）。序列号按 **UTC** 还原并取 UTC 年月日 ——
用本地时区取会把 `46265.72`（8/31 17:16 UTC）在东八区推成 9/1。认不出来的原值保留在明细表里，
但不参与日期筛选，绝不会显示成 1970 或 `NaN`。

## 导入

左侧「导入 AirScript 数据」可以直接粘贴 WPS 脚本编辑器「**一键复制日志**」按钮复制出来的整段内容 ——
带 `[19:59:44] [info] ` 时间戳前缀、`(看板导出-xxx.js:1:2396)` 来源后缀、`@@n@@…@@/@@` 分段标记的原始日志，
不需要手工清理。

导入失败时会给出可操作的具体原因，而不是一句「解析失败」：

- `分段不连续：缺少第 3 段（共收到 5 段，编号最大到 6）`
- `第 2 段只复制到了开头、缺少结尾的 @@/@@（日志里共 6 段，完整的只有 5 段）`
- `JSON 解析失败：断在第 722 个字符，落在第 2 / 6 段内（该段第 23 个字符）。断点附近：…⟪断在这里⟫…`
- `日志开头声明共 6 段，实际只解析出 4 段，末尾没有复制全`

导入成功后左上角显示战区与记录数，导入框显示「导入成功：一战区 · 21 条记录（热线 21 · 未购 0）」。

## 脚本特性

- **按字段名读取**：源表调整字段顺序、插入新列都不影响结果
- **只读**：不创建表、不写入、不修改任何记录
- 自动识别表名中的「热线日报」「未购日报」关键字，跳过 📊 统计表
- 兼容人员/关联/选项等对象型字段，日期兼容 ISO 串、`yyyy/MM/dd` 文本与 Excel 序列号

## 跨战区汇总

在每个战区分别运行脚本，把多份 JSON 的 `detail` 数组合并成一份再导入，看板顶部会自动出现「战区」筛选，可做总管理系统的全量视图。

## 技术说明

单文件 HTML，零依赖（图表全部为手写 SVG），支持浅色/深色主题自动跟随系统。配色经过色盲可辨性（CVD ΔE）与对比度校验。
